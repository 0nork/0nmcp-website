03 — How It Works
Three execution modes.
Every workflow pattern covered.
Any AI application calls the 0nMCP API with a task. The platform selects the optimal tools, execution pattern, and AI model — and returns a scored result.
→
Mode 01
Pipeline
Tools execute sequentially. Output of each step becomes input to the next. Used for structured workflows where order and data transformation matter.
Enrich lead → Score ICP → Draft email → Send via SMTP
⇉
Mode 02
Assembly Line
Multiple tools run in coordinated parallel tracks and converge on a final output. Optimized for complex tasks requiring simultaneous data gathering.
LinkedIn + ZoomInfo + Stripe → unified company profile
✦
Mode 03
Radial Burst
A single trigger fans out to N tools simultaneously and aggregates all results. Used for maximum-breadth queries and competitive model scoring.
Broadcast prompt → GPT-4o + Claude + Gemini → highest confidence answer returned
